4. Hide privacy commitments until FAQ section

5. Develop unique, warm voice
6. Design mobile-first, scale up

8. Use simple, everyday language
9. Test accessibility before launch

## 📞 TROUBLESHOOTING GUIDE

### "The messaging feels too corporate"
→ Re-read tone guidelines in HOMEPAGE_REDESIGN.md
→ Replace buzzwords with real, human language
→ Run test: Can a 12-year-old understand it?

### "I'm not sure which Nepali translations to use"
→ Use exact copy from NEPALI_CONTENT_GUIDE.md
→ Test with native Nepali speakers
→ Follow cultural notes section

### "The timeline seems tight"
→ Phase work in parallel if possible (design + content)
→ Prioritize: Hero → How It Works → CTAs → Trust
→ Use component templates (don't build from scratch)

### "Mobile layout feels cramped"
→ Increase padding/margins (use spacing scale)
→ Reduce font sizes incrementally
→ Stack cards to single column
→ Test on real devices

### "SEO feels too complex"
→ Focus on meta title & description first
→ Add FAQ schema (template provided)
→ Implement hreflang tags
→ Test with Google's schema validator

### "Users aren't clicking CTAs"
→ Check CTA button color contrast
→ Make button text more action-oriented
→ Reduce friction (how many clicks to signup?)
→ A/B test button labels
